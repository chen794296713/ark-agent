# Agent portraits

These five original illustrated AI coworkers were generated with the built-in OpenAI image generation tool for the user-approved team-directory direction. They represent roles, not real employees or customers.

Each PNG includes its exact generation prompt in embedded metadata. The approved composition and prompt are retained in `.impeccable/mocks/decision/team-directory.png` and its sidecars. The individual portraits were generated separately from reference crops; no cropped mockup pixels ship as artwork.

All five portraits are 768 × 1152 pixels and are served through Next.js Image for responsive delivery. Their roles and local paths are defined in `lib/agent-catalog.ts`.
